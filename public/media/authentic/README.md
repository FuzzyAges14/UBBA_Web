# Authentic UBBA media (`@ubbatkd`)

Stills and short web video clips downloaded from the academy Instagram
account. Captions are recorded in `MANIFEST.json`.

## Placement policy

Use the **Instagram caption** to decide where an asset may appear. Do not
infer from visual similarity alone.

| Caption theme | Allowed | Not allowed |
| --- | --- | --- |
| Back-to-school promo flyers | Social feed / promo only | Program cards, Tiny Tigers, adult heroes, camp feature |
| Fall schedule / BBC training announcement | Social feed only | Any program or camp photo slot |
| Summer Camp zoo / crafts / animals / fitness / playground / field trip / group / smiles | Summer Camp page, camp hub tile (group/smiles), social feed | Adult programs, birthday package art |
| “Happy Birthday …” shoutout (board-break photo) | Social feed only | Birthday Parties page (caption is a wish, not party photography) |

Adult / self-defense / weapons program photography is still missing from this
set — leave those slots text-first rather than borrowing camp photos.
